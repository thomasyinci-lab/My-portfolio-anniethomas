# AI Usage Notes

I used AI tools as a learning assistant throughout this project. Below is a summary of how I used them and what I learned.

## Tools Used

- **DeepSeek:** Used for step-by-step guidance on Figma structure, CSS layouts, and JavaScript logic. This was my primary tool for structuring the project and debugging errors.
- **ChatGPT:** Used for general coding questions, checking syntax, and getting alternative explanations when I was stuck.
- **Claude:** Used for refactoring advice, design system recommendations, and additional explanations on best practices.

## How I Used AI

### 1. Figma Design Guidance

I used AI to help me understand how to structure my Figma file. It explained how to use frames, groups, and components to organize my layers so they would translate cleanly into HTML and CSS later. I then applied these principles to build my own design system and page mockups.

### 2. Debugging CSS Layouts

When my mobile layout wasn't stacking correctly, I asked AI to explain how `flex-direction: column` works with `@media` queries. It walked me through the logic, and I used that explanation to fix my own CSS.

### 3. Understanding APIs

I was new to using `fetch` and APIs. AI provided a basic example of how to use `async/await` to pull data from the GitHub API. I used this as a starting point to write my own `loadRepos()` function, including my own error handling and loading states.

### 4. Form Validation and JavaScript

AI helped me understand regular expressions (regex) for email validation and how to manipulate the DOM to show custom error messages. I adapted their suggestions to fit my specific design and requirements.

## What I Learned

Through using AI as a tutor, I gained a much better understanding of:

- How to structure a responsive layout using Flexbox and Grid
- How to use CSS custom properties for theming
- How to fetch data from an API and handle errors
- How to write custom form validation in JavaScript

I understand the final code in this repository and can explain the design and functionality choices I made.
