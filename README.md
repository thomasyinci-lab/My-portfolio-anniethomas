# Annie Thomas | Portfolio

## About

A personal portfolio website built for my Year 5 Internet and Web Services assignment at MUBAS. It showcases my engineering projects, skills, and contact information.

## Live Site

https://thomasyinci-lab.github.io/My-portfolio-anniethomas/contact.html

## Figma Design File

(https://www.figma.com/design/bPCibHRKdn37o26rfmcWed/BOTH-VERSIONS?node-id=0-1&t=quCZpW8K2OjGoNAQ-1)

## How to Run Locally

1. Clone this repository.
2. Open `index.html` in your browser.

## Technologies Used

- HTML5 (Semantic elements)
- CSS3 (Grid, Flexbox, Custom Properties, Media Queries)
- JavaScript (Fetch API, DOM manipulation, Form validation, Local Storage)
- Figma (Design & Prototyping)

## Features

- Fully responsive design (Desktop & Mobile)
- Dark/Light mode toggle with saved preference
- Custom form validation with error messages
- Live GitHub API integration on the Projects page
- Custom 404 page and a technical article
